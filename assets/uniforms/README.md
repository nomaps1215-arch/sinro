# 制服の画像を置く場所

カードの右側に敷く制服の画像をここに置く。ファイル名は `data/schools.json` の `id` に合わせる。

```
assets/uniforms/pref-mikunigaoka.jpg
assets/uniforms/priv-seikyo-gakuen.jpg
```

置いたら `data/schools.json` の該当レコードに次の1行を足して、`python tools/build_bundle.py` を実行する。

```json
"uniformImage": "assets/uniforms/pref-mikunigaoka.jpg",
```

指定が無い学校は、`js/uniform-art.js` が制服の種類（ブレザー／セーラー／学ラン／標準服／私服）から
自作の簡略図を描く。制服の種類そのものが未取得の学校には何も表示しない。

## 著作権について（重要）

**学校の公式サイトや制服店・受験情報サイトに載っている制服の写真やイラストは、それぞれの著作物。
自動で取得してここに置くことはできないし、そのまま公開すると権利侵害になる。**

このフォルダに置いてよいのは次のいずれか。

- 学校から使用許諾を得た画像
- 自分で撮影した写真（被写体が特定の生徒と分かる場合は本人の同意も必要）
- 自分で描いたイラスト
- ライセンス上、再配布と改変が明示的に許可されている画像

判断がつかないものは置かないこと。何も置かなくても、種類に応じた簡略図が出るので機能上の問題はない。

GitHub Pages などで公開する場合は、置いた画像がそのままインターネット上に公開される点に注意する。
